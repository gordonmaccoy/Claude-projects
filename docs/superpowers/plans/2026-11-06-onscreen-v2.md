# OnScreen V2 Implementation Plan

**Goal:** Deliver the approved V2 specification on the existing development branch.
**Architecture:** Express and Socket.IO with PostgreSQL as authority. Row-locked session documents hold immutable test snapshots, enrollment, drafts, incidents and grades; account-owned library rows hold editable tests. Supabase validates professor identity.
**Tech Stack:** Node, Express, pg, Socket.IO, Supabase Auth, fflate, esbuild; node:test and embedded PostgreSQL (PGlite).
**Spec:** ../specs/2026-11-06-onscreen-v2.md
