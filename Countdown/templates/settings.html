Professor Photos

How to add a professor photo:

  1. Prepare a square photo (JPG or PNG recommended)
  2. Rename the file using the professor's name in lowercase with underscores:
    Dr. Kim → dr_kim.jpg
    Prof. Lee → prof_lee.png
  3. Place the file in this folder on your computer:
    Countdown/static/images/professors/
  4. Restart the app — the photo appears on the homepage card automatically.

Supported formats: jpg, jpeg, png, webp
