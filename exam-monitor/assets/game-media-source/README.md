# Examio Game Mode media sources

The current set contains 25 original illustrations made for Examio. Each
number uses a distinct visual treatment, such as foil, knit, candy, a theatre
marquee, a balloon, a candle, a road-trip sign or a segmented display. The
instructor-provided images were used only to identify broad themes. No source
pixels, stock watermarks, brand marks, or copied designs are embedded.

The generators are organized in `intro/`; #15 is the separately drawn blue
3D numeral from `intro/make_fifteen.py`. Font license notices are kept with the
generator sources. Only the WebP artwork and MP3 gameplay cues are served.

The game uses edited excerpts of the instructor-provided sound effects listed
below. Use them as in-game cues, not as standalone sound downloads.

- [Old Zildjian Gong Quite Natural, SaftJesus (Freesound) via Pixabay](https://pixabay.com/sound-effects/musical-old-zildjian-gong-quite-natural-34294/)
- [Loud Fanfare Trumpet Effect #04, AberrantRealities via Pixabay](https://pixabay.com/sound-effects/musical-loud-fanfare-trumpet-effect-04-412050/)
- [Cheering Crowd, Universfield via Pixabay](https://pixabay.com/sound-effects/people-cheering-crowd-242638/)

All three catalog entries list the [Pixabay Content License](https://pixabay.com/service/license-summary/).
The excerpts are trimmed, faded, and integrated with timed game events.
The lobby, countdown, and score-counting music remain unchanged.
Earlier template and synthesized audio generators are retained as fallbacks.
They do not describe the current cards or the selected cue recordings.
